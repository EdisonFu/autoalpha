# QuantaAlpha: An Evolutionary Framework for LLM-Driven Alpha Mining

**ArXiv**: https://arxiv.org/abs/2602.07085
**作者**: Jun Han, Shuo Zhang, Wei Li et al.（多机构合作，24 位作者）
**年份**: 2026

---

## 核心贡献

将**遗传算法的进化操作**（变异、交叉）应用于 LLM Alpha 挖掘的完整轨迹层面，而非单个因子层面。每一次挖掘"运行"被视为一条轨迹（trajectory），轨迹可以在种群层面进行变异和交叉，产生新的挖掘策略。

---

## 系统架构

```
种群初始化（多条挖掘轨迹）
    ↓
各轨迹独立执行：假设 → 表达式 → 评估
    ↓
轨迹级遗传操作：
  - 变异：替换轨迹中表现最差的子步骤
  - 交叉：将两条轨迹的优秀片段重新组合
    ↓
语义一致性验证（三角检查）
    ↓
次优步骤定位 → 局部修订
    ↓
收敛 or 达到代数上限 → 输出最优因子集
```

---

## 核心创新

### 1. 轨迹级进化（Trajectory-level Evolution）
- 以前的方法：单个因子 → 评估 → 修改因子
- QuantaAlpha：整条挖掘运行轨迹 → 评估 → 变异/交叉轨迹
- **意义**：探索的是"如何挖掘"的策略空间，而不只是"挖掘到什么"的结果空间

### 2. 语义一致性三角（Semantic Consistency Triangle）
强制验证三层语义对齐：
```
市场假设 ←→ 数学表达式 ←→ 可执行代码
```
任意两层不一致 → 整条轨迹标记为无效，不进入下一代

### 3. 次优步骤定位（Suboptimal Step Localization）
- 识别整条轨迹中哪个步骤导致了最终失败
- 只修订该步骤，保留其他步骤
- 避免"全部推倒重来"的浪费

### 4. 冗余与复杂度管理
- 跨轨迹去重：同一代中不允许高度相似的因子共存
- 防止种群早熟收敛（premature convergence）

## 对 AutoAlpha 的启发

### 1. 轨迹记录与重放（中期引入）
不只记录单个因子的结果，而是记录**完整的生成轨迹**：
```
{
  "session_id": "...",
  "paper": "...",
  "hypothesis_chain": [...],
  "factor_specs": [...],
  "eval_results": [...],
  "success_rate": 0.3
}
```
将高成功率的轨迹保存为"模板轨迹"，新会话可以从模板出发而非从零开始。

### 2. 因子扩展的"交叉"操作
当前 `factor_extension_agent` 只对单个因子做变体。可以引入**双因子交叉**：
```
因子A（动量方向）× 因子B（波动率过滤）→ 交叉因子C
逻辑：在高波动率状态下激活动量信号
```

### 3. 语义三角验证（直接可做）
在 `pipeline.py` 的流水线中，`factor_extract` → `factor_implement` 之间增加对齐检查：
- 假设（自然语言） ↔ 公式（数学表达式）：LLM 验证
- 公式（数学表达式） ↔ 代码（Python）：LLM 验证

### 4. 次优步骤定位
评估失败后，不要盲目重写全部代码，而是先定位：
- 是假设提取错了？
- 是公式转换错了？
- 还是代码实现错了？
针对性修复对应层次。
