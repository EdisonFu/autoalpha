## 跨论文共识：六大设计原则

1. **闭环强制** — 评估结果必须结构化反馈，不能是二元黑盒
2. **多样性约束** — AST/Jaccard/遗传变异，数学强制而非依赖 LLM 自觉
3. **语义三角对齐** — 假设 → 公式 → 代码，三层语义必须一致
4. **经验记忆** — 历史成功/失败轨迹蒸馏为可检索知识，避免重复探索
5. **结构化探索** — 有限网格覆盖 > 无限随机漫游
6. **因子衰减对抗** — 复杂度控制 + 原创性约束 + 跨市场验证

## AutoAlpha 改进优先级

```
🔴 高优先级（立即可做）
  - 假设→代码语义对齐验证
  - 评估失败故障分类 + 定向修复策略
  - 修复循环收敛控制（停滞/恶化熔断）

🟡 中优先级（第二轮）
  - 因子扩展 Jaccard/AST 多样性过滤
  - 历史成功因子经验记忆与检索
  - 结构化探索网格（信号族×算子×时间×处理）

🟢 低优先级（长期优化）
  - 赌徒调度/优先级加权探索
  - RL 驱动的因子动态激活
  - 多市场泛化验证
```
