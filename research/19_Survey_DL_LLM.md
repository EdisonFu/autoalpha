**ArXiv**: https://arxiv.org/abs/2503.21422
**作者**: Bokai Cao, Saizhuo Wang, Xinyi Lin et al.（香港科技大学 + Microsoft Research）
**年份**: 2025

## 核心贡献

系统梳理了从传统机器学习、深度学习到大语言模型在量化投资领域的演进历程，是该领域最全面的综述论文。对 AutoAlpha 有战略层面的指导意义。

---

## 技术演进路线图

### 第一代：传统 ML（2010-2018）
```
手工特征工程 → 机器学习分类/回归
  - 随机森林
  - 梯度提升（XGBoost/LightGBM）
  - SVM
局限：特征工程依赖人工，无法处理非结构化数据
```

### 第二代：深度学习（2018-2022）
```
自动特征提取 → 深度网络预测
  - LSTM/GRU：时序建模
  - Transformer：注意力机制
  - GNN：股票间关系建模
局限：缺乏经济直觉，黑盒，难以解释
```

### 第三代：LLM 时代（2022-至今）
```
预训练金融知识 → 智能体系统
  - 自然语言理解：从新闻/研报提取信号
  - 代码生成：因子公式自动实现
  - 推理能力：多步骤量化研究推理
  - 自主智能体：闭环自动化流水线
```

## 关键发现

### 1. LLM 在量化研究中的五大能力
1. **情感分析**：理解市场情绪、新闻事件
2. **事件提取**：识别盈利公告、政策变化
3. **数学推理**：验证因子逻辑的数学一致性
4. **多模态分析**：融合文本、数值、图像
5. **检索增强生成（RAG）**：利用历史知识库减少幻觉

### 2. 当前主要挑战
| 挑战 | 描述 | 解决方向 |
|---|---|---|
| 时间泄露 | 训练数据包含测试期信息 | 严格的时序分割 |
| 幻觉 | LLM 生成不存在的字段/算子 | RAG 锚定 + 确定性验证 |
| 市场分布漂移 | 历史规律在未来失效 | 持续学习 + 因子衰减监控 |
| 可解释性 | 黑盒模型监管风险 | 坚持公式化因子 |
| 过拟合 | 回测良好但实盘失效 | 走样外验证 + 复杂度控制 |

### 3. 未来研究方向
- **持续学习**：模型随市场变化持续更新
- **关系数据建模**：股票间相互影响的图建模
- **更强的过拟合控制**：超越简单的正则化
- **多资产类别扩展**：期货、债券、外汇

## 对 AutoAlpha 的启发

### 1. 防止时间泄露的最佳实践
确保我们的代码生成要求中明确强调：
```python
_ANTI_LOOKAHEAD_RULES = """
严格禁止的模式：
1. 不使用当日收盘价预测当日收益（用前一日收盘价）
2. 所有 rolling 计算必须使用 closed='left' 或 shift(1)
3. 不使用 expanding().last()（可能包含未来信息）
4. 标准化时只用截止到当日的历史统计量
"""
```

### 2. 持续监控因子健康度
建立定期任务，监控已入库因子的实时表现：
- 每月重新计算 IC
- 检测 IC 显著下降（衰减警报）
- 自动触发重新评估或替换

### 3. 坚持公式化因子（可解释性原则）
综述指出：黑盒因子面临监管风险和信任问题。我们的系统坚持生成**公式化、可解释的因子代码**，这是正确方向，要在代码质量上严格要求。

### 4. 走样外验证规划
在评估中增加走样外（Out-of-sample）验证期：
- 训练期：过去 3 年
- 验证期：过去 1 年（不用于优化）
- 报告中同时展示样本内和样本外表现
